A 24/7 AI agent team on 4 computers Đội AI agent 24/7 trên 4 máy

I run my AI work like a small company. One main agent plans the work and hands jobs to worker agents on each machine. Every agent writes what it does to one shared log, so I can check any result. Phong vận hành công việc AI như một công ty nhỏ. Một agent chính lên kế hoạch và giao việc cho các agent trên từng máy. Agent nào làm gì cũng ghi vào một sổ chung, nên kết quả nào Phong cũng kiểm lại được.

  • ▸ 4 machines: Mac Studio (planning and R&D), Mac mini M5 Pro (24/7 production server), Mac mini M4 (research), Windows mini PC (video work), plus a NAS for media. 4 máy: Mac Studio (điều phối và R&D), Mac mini M5 Pro (máy chủ chạy 24/7), Mac mini M4 (nghiên cứu), mini PC Windows (làm video), cùng một NAS lưu media.
  • ▸ 25 agents built on Claude Code, Google Gemini and ChatGPT, each with one clear role. 25 agent dựng trên Claude Code, Google Gemini và ChatGPT, mỗi agent một vai trò rõ ràng.
  • ▸ Shared memory: 2,156 lessons that every agent can search before it acts, and 567 tracked jobs and questions on one board. Bộ nhớ chung: 2.156 bài học mà agent nào cũng tra được trước khi làm, và 567 việc, câu hỏi được theo dõi trên một bảng.
  • ▸ Quality checks: an AI judge scores important decisions before the agents act, and every claim must be checked against live data. Kiểm tra chất lượng: một AI giám khảo chấm điểm các quyết định quan trọng trước khi agent làm, và mọi thông tin phải kiểm lại bằng dữ liệu thật.
  • ▸ Data: one PostgreSQL database holds the log, the content calendar and a library of 3,736 media files. Dữ liệu: một database PostgreSQL chứa sổ hoạt động, lịch nội dung và thư viện 3.736 file media.
